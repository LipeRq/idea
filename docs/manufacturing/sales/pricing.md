# 見積アシスト(仮称) 提供メニューと価格の仮説

- 位置づけ:**社内の検討資料**です。お客様に出すときは「7. お客様向けの価格表(案)」だけを提案書に貼ります。
- もとになる資料:[use-cases.md](../use-cases.md) 5.7(価格・提供形態の仮説)、5.1(作業時間の仮説)、5.3(API費用の推定)、1章の判断事項4
- **ここにある価格はすべて仮説です。** 実際に販売した実績はまだありません。use-cases.md の方針どおり、仮説のまま2〜3社に提示して反応を見てから決めます。
- 金額はすべて税別です。

## 1. 価格を考えるうえでの前提

| 前提 | 内容 | 根拠 |
|---|---|---|
| お客様の障壁は「価格」より「どこに使えばよいか分からない」「事例がない」「人がいない」 | 診断を無料にし、PoC(試験導入)で効果を実測してから本導入を判断していただく | use-cases.md 2.3([S7][S9]) |
| AI導入後の課題の1位は「ランニングコストが高い」(44.0%) | 月額は、削減できる時間で説明できる水準に抑える | use-cases.md 2.3([S7]) |
| 効果の数値は仮説 | 作業時間の短縮(1件あたり35〜110分)は公的統計がなく、筆者の仮説。PoCで実測して置き換える | use-cases.md 5.1 |
| 見積アシストの導入実績はまだない | 「実績」ではなく「PoCで御社のデータで測る」ことを価値として売る | — |

### 2.1 初期導入費の幅の考え方(仮説)

初期導入費は、お客様のデータの整い具合(use-cases.md 5.4 のレベル)で変わります。

| レベル | お客様の状態 | 主な作業 | 価格帯の目安(仮説) |

## 4. 費用対効果の試算式

### 4.1 月の削減時間と金額換算

```
月の削減時間[時間] = 月の引き合い件数 × 1件あたりの削減時間[分] ÷ 60
月の削減額[円]     = 月の削減時間 × 時間単価[円/時間]
```

- 1件あたりの削減時間は、use-cases.md 5.1 の仮説(現状65〜125分 → 導入後15〜30分、削減35〜110分)の中から**控えめに60分**を置きます。さらに「実現が半分だった場合」として30分も示します。
- 時間単価は、自社のAI導入診断ツールの初期値3,000円を使います。社長・工場長の時間をいくらと見るかはお客様の経営判断なので、提案時は【御社の時間単価】に置き換えます。
- **金額換算は「その時間を別の仕事に回せる」という意味です。** 人件費が直接減るとは限りません。

**試算例(use-cases.md 5.7 と同じ):** 引き合い120件/月 × 60分 = 120時間/月。× 3,000円 = 月36万円相当。実現が半分でも月18万円相当。

**件数別の早見表(時間単価3,000円の場合)**

| 月の引き合い件数 | 削減30分/件のとき | 削減60分/件のとき |
|---|---|---|
| 30件 | 15時間 → 4.5万円 | 30時間 → 9万円 |
| 60件 | 30時間 → 9万円 | 60時間 → 18万円 |
| 120件 | 60時間 → 18万円 | 120時間 → 36万円 |
| 200件 | 100時間 → 30万円 | 200時間 → 60万円 |

### 4.2 月額の損益分岐となる件数

```
損益分岐の件数[件/月] = 月額[円] ÷(1件あたりの削減時間[時間] × 時間単価[円/時間])
```

| 月額 | 削減60分/件のとき | 削減30分/件のとき |
|---|---|---|
| 5万円 | 約17件/月 | 約34件/月 |
| 10万円 | 約34件/月 | 約67件/月 |

### 4.3 初期費用の回収期間

```
回収期間[か月] =(PoC費用 + 初期導入費)÷(月の削減額 − 月額)
```

| 月の件数 | 削減/件 | 月の削減額 | 価格の中央値で計算(一時費用215万円、月額7.5万円) | 価格の下限で計算(一時費用130万円、月額5万円) |
|---|---|---|---|---|
| 30件 | 30分 | 4.5万円 | 月額を下回る(回収できない) | 月額を下回る(回収できない) |
| 30件 | 60分 | 9万円 | 約143か月 | 約33か月 |
| 60件 | 30分 | 9万円 | 約143か月 | 約33か月 |
| 60件 | 60分 | 18万円 | 約20か月 | 約10か月 |
| 120件 | 30分 | 18万円 | 約20か月 | 約10か月 |
| 120件 | 60分 | 36万円 | 約8か月 | 約4か月 |

一時費用の中央値 = PoC 40万円 + 初期導入 175万円。下限 = PoC 30万円 + 初期導入 100万円。

**この表から分かること(社内向け):**
- 引き合いが**月60件未満**の会社では、作業時間の削減だけで初期費用を回収するのは難しい試算になります。小さい会社向けには、初期導入の範囲を絞ったプランや、月額の下限を下げたプランが必要かもしれません【要判断】。
- 月120件以上の会社では、仮説の半分の効果でも2年弱で回収できる試算です。最初の提案先は、引き合いの多い会社を優先するのが合理的です。

### 4.4 金額にしにくい効果(KPIで追う)

次の効果は事前に金額にするのが難しいため、試算には入れず、導入後にKPI([proposal-template.md](proposal-template.md) の9章)で追います。

- 回答が速くなることによる受注の増加(回答リードタイム、受注率)
- 赤字案件の早期発見(見積と実績原価の差)
- 受注後の手戻りの減少(仕様確認の件数)
- 見積が社長以外でも作れるようになること(属人化の解消、技能継承)

## 5. 原価の目安(社内向け)

| 項目 | 目安 | 根拠 |
|---|---|---|
| AIの利用料(1件あたり) | 約0.9ドル(1ドル150円で約140円)。図面2枚と仕様書10ページ、入力約15万トークン・出力約1.5万トークンと仮定した**推定** | use-cases.md 5.3([S32][S35]) |
| AIの利用料(月120件) | 約1.7万円 | 同上 |
| AIの利用料(月200件=月額の上限) | 約2.8万円 | 同上の計算 |
| 国内での処理を選んだ場合 | AIの利用料が約10%高くなる | use-cases.md 5.9([S34]) |

- 実際のAPIでの費用はまだ計測していません(apps/quote-assist/README.md の「制約・未実装」)。PoCで計測して見直します。
- 月額5万円で200件まで使われると、AIの利用料だけで半分以上になります。件数の上限を段階にする(例:〜100件で5万円、〜200件で10万円)などの設計が必要です【要判断】。
- AIの料金やモデルが変わると原価も変わります。月額に含めるAI利用量に上限を設けます(use-cases.md 5.9)。

## 6. 補助金の扱いの注意

| 注意点 | 内容 |
|---|---|
| 登録が前提 | 「デジタル化・AI導入補助金」(旧IT導入補助金)の対象にするには、IT導入支援事業者の登録と、ツールの登録が必要です(use-cases.md 2.6 [S15])。**登録していない間は「補助金の対象です」と言わない。** |
| 登録するかどうか | 登録の手間と、お客様の負担が下がる効果を比べて判断します(use-cases.md 判断事項4)【要判断】 |
| 金額を約束しない | 補助率・上限額・対象経費は年度や申請枠で変わります。「実質○円」のような表現は使わず、最新の公募要領を確認するよう案内します |
| 採択は保証されない | 申請しても採択されないことがあります。採択を前提にした契約・スケジュールにしない |
| 契約の時期 | 交付決定の前に契約・支払いをすると対象外になる扱いが一般的です。公募要領で確認し、スケジュールに反映します |
| その他の補助金 | 自治体のDX・省力化の補助金なども、お客様の地域の公募要領で確認します(当社が申請を代行するかどうかは【要判断】) |

## 8. 決めること(要判断)

| # | 判断事項 | 筆者の推奨・メモ |
|---|---|---|
| 1 | 価格帯をこのまま2〜3社に提示するか | 仮説のまま提示して反応を見る(use-cases.md 判断事項4) |
| 2 | PoC費用を初期導入費に充当するか(例:本導入したらPoC費用の一部を差し引く) | 本導入への移行を後押しできる。充当の割合を決める |
| 3 | 月額の件数上限と超過時の扱い | 5章のとおり、200件まで5万円だと原価が重い。段階制を推奨 |

| 5 | 補助金対応(IT導入支援事業者の登録) | 登録の負担と、顧客の負担軽減の効果を比べて判断 |
| 6 | 支払い条件(PoCの前払い・分割、月額の最低契約期間) | 【要判断】 |
