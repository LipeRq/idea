当社は、適正な手段により、次の情報を取得します。本サービスには会員登録の機能はありません。

### 3-1. 診断ツールで取得する情報

**(1) 診断のために入力いただく情報**

| 情報 | 必須/任意 | 取扱い |
|---|---|---|
| 会社名 | 任意 | 結果画面と PDF の表示にだけ使います。AI には送りません |
| 業種、従業員規模、時間単価、業務ごとの月間の作業時間、IT環境に関する回答、AIで優先したいこと | 必須(優先したいことは任意) | 試算の計算と、AI によるレポート文章の作成に使います |
| いま困っていること(自由記述・1,000文字以内) | 任意 | AI によるレポート文章の作成に使います |

- 入力内容と診断結果は、当社のサーバーに保存しません(診断・PDF作成のリクエストを処理する間だけメモリ上で扱います)。PDF はリクエストのたびにサーバーで作成してお返しし、保存しません。
- AI によるレポート文章の作成のため、上表のうち会社名を除く情報と、それをもとに計算した試算結果を、第6項の Anthropic, PBC(米国)に送信します(第7項)。
- **「いま困っていること」には、個人を特定できる情報(氏名・連絡先など)や、機密情報を書かないでください。**

**(2) 無料相談の申し込みでお預かりする情報**

| 情報 | 必須/任意 |
|---|---|
| 会社名、氏名、メールアドレス、相談したい内容 | 必須 |
| 電話番号 | 任意 |
| 個人情報の取扱いへの同意の有無 | 必須 |
| 診断結果の要約(業種、従業員規模、年間削減見込み額・時間、準備度、優先施策の上位3件)と申し込み日時 | 自動で添付(診断の入力からサーバーで計算し直したもの) |

- お申し込みの内容は、当社のサーバーには保存せず、当社が利用する顧客管理・業務連絡のサービス(第6項の Salesforce【および/または】Slack【等】)に送信し、そこで管理します。
- 「いま困っていること」の記入内容は、申し込みの送信先には送りません。

> 【確認メモ】申し込みの送信先は環境変数 `SALESFORCE_ORG_ID`(Salesforce Web-to-Lead)と `LEAD_WEBHOOK_URL`(Slack の Incoming Webhook、またはそれ以外の任意の Webhook)で決まり、両方を設定すると両方に送られます(`apps/diagnosis/src/lib/lead/deliver.ts`)。実際に使う送信先だけを残してください。Slack 以外の Webhook(例:Microsoft Teams、Zapier 等)を使う場合は、その事業者を第6項に追記してください。

**(3) 自動的に取得する情報**

| 情報 | 目的 | 取扱い |
|---|---|---|
| IPアドレス | 回数制限(送信元ごとに1時間あたりの診断・PDF作成・申し込みの回数を数える)、ボット対策 | サーバーのメモリ上ではおおむね1時間保持します。複数のサーバー間で回数を共有する記録(第6項の Upstash)には、IPアドレスをそのまま置かず、ハッシュ値に変換したものを1時間の有効期限付きで保存します。ボット対策を有効にしている場合は、確認のため Cloudflare に送信します |

### 3-2. 棚卸しツールで取得する情報

**(1) 標準の仕様書(AI を使わない機能)**

- お使いのファイル(Excel・Access ファイル)は、**お使いのブラウザの中だけで解析し、当社のサーバーを含む外部には送信しません**。解析結果もブラウザのメモリ上にだけあり、タブを閉じると消えます。当社は、ファイルの内容も解析結果も取得しません。
- 棚卸しツールは、アクセス解析のタグ・Cookie・ブラウザの保存領域(localStorage 等)を使用しません。

**(2) AI版(詳しい仕様書)を利用する場合**

AI版は、送信内容を画面で確認し、同意いただいたうえで「同意してAI版を作成」を押したときだけ、次の情報を当社のサーバーを経由して Anthropic, PBC(米国)に送信します。

| 区分 | 内容 |
|---|---|
| 送らないもの | ファイル本体、シートのセルの値(データ本体)、元のファイル名(「対象ファイル.xlsm」等に置き換えます)、ファイルの指紋(SHA-256)・大きさ、文書のプロパティに記録された作成者・最終更新者・会社名・タイトル・作成アプリの名前と版、作成・更新の月日と時刻(年だけ送ります)、解析の警告 |
| 伏せ字にして送るもの | パターンにより検出できたパスワード(「****」に置き換えます。検出には漏れがありえます) |
| そのまま送るもの | マクロ(VBA)のソースコード(コメント・文字列を含みます)、Access のクエリの SQL(送らない選択ができます)、シート名・数式の例・名前定義、テーブル名・列名・行数、Access のフォーム・レポート・マクロ・モジュールの名前、リンクテーブルの参照先、シートのボタン等の文字と登録マクロ名、VBA プロジェクト名・参照設定のパス、作成・更新の年、コードから取り出した SQL 文・接続文字列・ファイルのパス・URL、呼び出し関係、機械的に検出したリスク・規模の件数 |
| ご注意 | **コード・コメント・数式・パスの中に氏名・メールアドレス・電話番号・会社名等が書かれている場合、それらは伏せ字にされずに送信されます。** 同意画面に、メールアドレス・電話番号・トークンなどに見える文字列を一覧表示しますが、検出は完全ではありません。個人情報を含むコードは送らないでください |
| アクセスコード | AI版を使うために当社がお渡しするコード。照合にだけ使い、保存・記録しません |
| 同意の版 | 同意画面の文言の版。同意時と現在の文言が同じかの確認にだけ使います |

- 当社のサーバーは、送信内容を処理中のメモリ上でだけ扱い、保存しません。サーバーのログには、結果の種類・件数・処理時間・推定トークン数・エラーの種類だけを記録し、送信内容・ファイル名・AI の出力・IPアドレス・アクセスコードは記録しません。
- AI が作成した文章はお使いのブラウザに返し、当社のサーバーには保存しません。

## 5. 第三者提供

当社は、次の場合を除き、あらかじめ本人の同意を得ることなく、個人データを第三者に提供しません。

1. 法令にもとづく場合
2. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき

6. 合併その他の事由による事業の承継に伴って提供される場合
7. その他、個人情報保護法その他の法令で認められる場合

## 7. 外国にある第三者への個人データの提供・外国での取扱い

### 7-1. 方針

第6項の事業者はいずれも外国(米国)の事業者です。当社は、外国にある第三者に個人データを提供する場合(取扱いを委託する場合を含みます)、個人情報保護法第28条に従い、次のいずれかの方法によります。

- 【A:あらかじめ本人の同意を得る方法。同意を得る際は、次の 7-2 の情報を提供します】
- 【B:提供先が、個人情報保護法施行規則で定める基準に適合する体制を整備している場合に、その体制の継続的な実施を確保するために必要な措置を講じる方法。本人の求めがあれば、当該措置に関する情報を提供します】

> 【確認メモ】A・B のどちらによるかを、事業者ごとに弁護士と決めてください(README の論点1・2)。棚卸しツールの AI版は、同意画面で「運営者のサーバーを経由して Anthropic 社(米国)の API に送信することに同意します」というチェックを必須にしているため A に寄せやすい一方、同意画面に表示しているのは国名と規約へのリンクだけです。7-2 の情報を本ポリシーで示し、同意画面から本ポリシーにリンクすること(環境変数 `NEXT_PUBLIC_PRIVACY_POLICY_URL`)で足りるかを確認してください。

### 7-2. 提供先の国、その国の制度、提供先の措置

**(1) 外国の名称**

アメリカ合衆国。

ただし、Anthropic の Claude API では、API の設定により、文章の生成処理が米国以外の地域で行われる場合があります(同社の説明では、既定の設定では利用可能ないずれの地域でも処理されうるとされ、データの保存は米国で行われます)。【当社は、生成処理を米国内に限る設定をしています / 処理の地域を特定できないため、その旨と理由をここに記載します】

> 【確認メモ】Anthropic の公式ドキュメント(Data residency)では、`inference_geo` の既定値は `"global"`(利用可能などの地域でも推論が実行されうる)、`"us"` を指定すると米国内に限られ、保存(Workspace geo)は現在 `"us"` のみとされています(2026-10-22 確認)。本リポジトリのコードは `inference_geo` を指定していません。Claude Console のワークスペース設定 `default_inference_geo` を `"us"` にすれば、コードを変えずに米国内に限れます(料金は同社の料金表によります)。どちらにするかで (1) の書き方が変わります。

**(2) 当該外国における個人情報の保護に関する制度**

米国には、日本の個人情報保護法に相当する、事業分野を問わず個人情報の保護を包括的に定める連邦法はなく、特定の分野・情報の種類ごとの連邦法、連邦取引委員会(FTC)による不公正・欺瞞的な行為の規制、および州法(カリフォルニア州消費者プライバシー法等)により保護が図られています。詳しくは、個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」(アメリカ)をご覧ください。
https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/

> 【確認メモ】上の要約は、弁護士が委員会の報告書の最新版と照らして確認してください。報告書には、政府による情報収集への協力義務に関する記載もあります。

## 8. Cookie・アクセス解析・外部への送信

### 8-1. 診断ツール

## 9. 安全管理措置

当社は、個人データの漏えい、滅失または毀損の防止その他の安全管理のため、次の措置を講じます。

**(1) 基本方針の策定**:個人データの適正な取扱いの確保のため、本ポリシーを定めています。

**(2) 個人データの取扱いに係る規律の整備**:取得、利用、保存、提供、削除・廃棄等の段階ごとに、取扱方法、責任者・担当者とその任務等について【取扱規程】を定めています。

**(3) 組織的安全管理措置**:個人データの取扱いに関する責任者を設置し、取り扱う従業者と取り扱う個人データの範囲を明確にしています。法令や【取扱規程】に違反している事実または兆候を把握した場合の報告連絡体制を整備しています。【取扱状況について、定期的に点検を実施しています】

**(4) 人的安全管理措置**:個人データの取扱いに関する留意事項について、従業者に【定期的な研修】を実施しています。個人データの秘密保持に関する事項を【就業規則等】に記載しています。

**(5) 物理的安全管理措置**:個人データを取り扱う機器、電子媒体および書類等の盗難または紛失等を防止するための措置を講じるとともに、事業所内の移動を含め、それらを持ち運ぶ場合に容易に個人データが判明しないよう措置を講じています。【実態に合わせて記入】

**(6) 技術的安全管理措置**

- 本サービスとの通信は暗号化(HTTPS)しています。
- 診断の入力、申し込みの内容、棚卸しツールの AI版の送信内容は、当社のサーバーに保存しません。サーバーのログには、氏名・連絡先・相談内容・送信内容・IPアドレス等を記録しない設計としています。
- 棚卸しツールでは、ファイルの解析をブラウザ内で行い、解析を行うプログラムからはブラウザの機能により一切の通信をできないようにしています。
- 回数を共有する記録には、IPアドレスをそのまま保存せず、ハッシュ値に変換して有効期限付きで保存しています。
- 外部サービスの認証情報(API キー等)は、ホスティング事業者の環境変数として管理し、アクセスできる者を限定しています。
- 申し込みの送信先(顧客管理・業務連絡のサービス)では、アクセスできる者を限定し、【多要素認証】を使用しています。【実態に合わせて記入】

**(7) 外的環境の把握**:当社は、第6項の外部サービスを通じて米国その他の外国で個人データを取り扱う場合があります。当該外国の個人情報の保護に関する制度を把握したうえで、安全管理措置を実施しています(第7項)。
