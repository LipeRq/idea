# 自分専用 LINE ボットの設計

- 毎朝のまとめは GitHub Actions、メモの整理は Cloudflare Workers で動かす。AI は DeepSeek
- どちらも無料の範囲で動く。費用は DeepSeek の利用料だけ(月30円ほど)
- 最終更新:2026-10-24(Claude・Vercel から DeepSeek・Cloudflare に変更)

---

## 1. 全体の形

```
毎朝のまとめ
  GitHub Actions(毎朝 6:40) → RSS を集める → DeepSeek が選んで要約 → LINE に1通送る

メモの整理
  LINE → Cloudflare Workers(/webhook) → キューに入れて、すぐ 200 を返す
       → キューから取り出す → DeepSeek で整理 → LINE に返信(だめならプッシュ)
```

| 決めたこと | 理由 |
|---|---|
| 毎朝のまとめは GitHub Actions | RSS 15本の読み取りは処理が重く、Workers の無料プランの上限(1回 10ms)を超えるため |
| メモはキュー(Cloudflare Queues)で処理する | 無料プランは、応答のあとに続けられる処理が30秒まで。キューならこの制限がない |
| AI は DeepSeek の `deepseek-flash` | 安い。写真も読める。JSON で答えさせ、プログラムで形を確かめる |
| AI は SDK を使わず fetch で呼ぶ | Node.js と Workers の両方で同じコードが動く |
| 保存はしない | 顧客の情報を残さない。結果は LINE のトークに残る |

---

## 2. 毎朝のまとめ

1. 15本の RSS を並行して読む(読めないものは飛ばし、最後に名前を出す)
2. 過去24時間の記事だけを残し、同じ記事を1件にまとめる
3. DeepSeek が分野ごとに4件まで選び、見出しと短い要約を書く
4. LINE に1通で送る(吹き出し5つ:要点と4分野)

- 記事のリンクは AI に書かせない。AI は記事の番号だけを返し、リンクはプログラムが付ける
- AI が使えないときは、見出しとリンクだけを送る

---

## 3. メモの整理

| 届いたもの | 返すもの |
|---|---|
| テキスト(20文字以上)・写真1枚 | 議事録 / 宿題と確認事項 / お礼メール |
| 写真を同時に複数枚 | 「1枚ずつ送ってください」 |
| 短い文・「使い方」・友だち追加 | 使い方 |
| 音声 | 「音声入力で文字にして送ってください」 |

- 返信は無料。整理に時間がかかって返信の期限を過ぎたら、プッシュ(月200通まで無料)で送る
- キューの処理が失敗しても送り直さない(二重に届くのを防ぐ)。失敗は LINE で知らせる

---

## 4. 安全

| 守ること | 方法 |
|---|---|
| 自分以外に反応しない | 送り主が `LINE_USER_ID` のときだけ処理する |
| なりすましを防ぐ | LINE の署名を確かめ、合わなければ 401 |
| メモをログに残さない | ログは種類と件数だけ |
| 秘密情報をコミットしない | キーは GitHub と Cloudflare の Secrets にだけ置く |

メモの内容は LINE と DeepSeek を通ります。DeepSeek のデータは中国のサーバーに保存されます。
顧客との秘密保持契約に合わない場合は、社名・人名を伏せて送ってください。

- 議事録の保存と、宿題の期日の通知
- 毎朝のまとめに天気や予定を入れる
