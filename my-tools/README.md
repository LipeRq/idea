# 自分専用の自動化ツール

日常の面倒な作業を、自分のためだけの小さなツールで減らすための置き場です。
顧客に提供するもの(`apps/`)とは分け、**社外には公開しません**(ポートフォリオにも載せない)。

## 今の状態

アイデアの候補と選び方は [ideas.md](ideas.md) を参照してください。

| ツール | 内容 | 状態 |
|---|---|---|
| [line-bot](line-bot/README.md) | 自分専用の LINE ボット。毎朝の情報まとめ(テクノロジー・株式投資・大きいニュース・ヘルスケア)と、打ち合わせメモの整理(議事録・宿題・お礼メールの下書き) | 実装済み・テスト済み。LINE・Cloudflare・DeepSeek・Secrets の準備待ち |

## 決まり

- 1つのツールは `my-tools/<ツール名>/` に置き、各フォルダに README(使い方・入力と出力・外部に送るもの)を書く。LINE から使う機能は `line-bot` に足す(LINE の送受信の部品を共用する)
- 送信・登録・支払いなど取り消せない操作は、最初は「下書きを作るところまで」にして、最後は自分で確認して押す
- API キー・メール本文・顧客の情報・領収書などの実データはコミットしない(`.env` と、各ツールの入力・出力フォルダは `.gitignore` に入れる)
- 1本目は「1〜2日で使い始められる大きさ」から作り、使いながら直す
