# AI導入診断ロジック設計

## 基本方針:計算はロジック、提案はAI

削減時間・削減額・投資回収月数は、すべて `src/lib/diagnosis/calculate.ts` の決まった式で計算する。Claudeには数値を作らせず、計算結果を前提にした施策の具体化・ロードマップ・注意点の文章だけを任せる。

- 同じ入力なら同じ数字が出る(説明責任を果たせる)
- 数字の根拠を顧客に説明できる(「AIがそう言っているから」にならない)
- 係数を変えれば試算全体を調整できる(`master.ts` に集約)

## 入力項目

| 区分 | 項目 | 用途 |
|---|---|---|
| 会社情報 | 業種、従業員規模、課題、優先したいこと | AIによる提案のパーソナライズ |
| 人件費 | 平均人件費(時給換算、初期値3,000円) | 削減額の計算 |
| 業務工数 | 10業務カテゴリの月間合計時間(全員分) | 削減時間の計算 |
| 準備度 | 6項目 × 4段階 | 準備度スコアと実現係数 |

## 計算式

### 1. 準備度スコア(0〜100点)

```
準備度スコア = Σ(項目の重み × 回答の点数 ÷ 3)
```

| 項目 | 重み |
|---|---|
| 業務データの保存場所 | 25 |
| 経営層の関与 | 20 |
| 業務手順の文書化 | 15 |
| 生成AIの利用状況 | 15 |
| 社内のIT担当者 | 15 |
| AI利用のルール | 10 |

0〜39点は「準備段階」、40〜69点は「導入可能」、70点以上は「推進段階」とする。

### 2. 実現係数(0.5〜1.0)

```
実現係数 = 0.5 + 0.5 × 準備度スコア ÷ 100
```

準備が整っていない会社では、ツールを入れても効果の半分程度しか出ないという前提を置く。

### 3. 業務ごとの削減効果

```
月の削減時間 = 月間工数 × 削減率 × 実現係数
年の削減額   = 月の削減時間 × 12 × 時給
```

削減率は業務ごとに保守的な目安を設定している(例:議事録60%、データ入力50%、経理30%)。

### 4. 難易度と前提条件

業務ごとに基本の難易度(低・中・高)を持つ。前提となる準備度の回答が「1以下」の場合は難易度を1段上げる。例えば社内文書の検索は、データが紙や個人PCに散らばっていると難しくなる。

### 5. 優先度と投資回収

```
優先度スコア   = 年の削減額 ÷ 難易度係数(低1.0 / 中1.6 / 高2.5)
投資回収の月数 = 初期費用 ÷ (月の削減額 − 月額費用)
```

優先度スコアの上位5業務を施策として提案する。初期費用・月額費用は難易度ごとの目安で、自社の料金表に合わせて `COST_BY_DIFFICULTY` を調整する。

## AIの役割

Claudeには、会社情報・計算結果・各業務の標準的な進め方(`master.ts` の `approach` など)を渡し、次の内容を構造化出力で返させる。

- 総評
- 上位5業務それぞれの具体的な進め方、ツール例、最初の一歩、注意点
- 3ヶ月のロードマップ
- 導入前に整えるべき準備
- 専門家と深掘りすべき論点(無料相談への導線)

APIキーがない場合やAIの呼び出しに失敗した場合は、マスターデータの標準文面でレポートを組み立てて返す。数字は同じものが出る。
